# ローカル最小版の引継ぎ

## 対象と結果

PR #1 の設計指摘対応、task 一覧、`skills -> ..\CodexSkill\skills` のリンク作成に続き、単一PCのローカル開発用 MCP サーバーを実装した。
公開用の初期版全体とは区別する。利用者の「再試の右舷」は「最小限」の誤変換と仮定した。
設定と起動方法は `README.md` と `.env.example`、後続作業は `tasks/tasks-status.md` にある。

OAuth 認可コードと PKCE、セッション、監査、固定版 Desktop Commander に委譲する検索・読取・部分編集・プロセス操作、MCP の7転送ツールを実装した。
待受けは loopback に限定し、実ユーザーの Desktop Commander 設定を変更せず、専用の設定領域を使う。
ダウンロードは固定複製の hash と送信バイトを照合する。上書き禁止のアップロードは原子的な確定と競合時の清掃を行う。

## 保護範囲と後続

設定保護は現在の設定実体とサービスが保持リンクで確認済みの過去実体に適用する。
同じ OS ユーザーが API 外から作る、未確認の過去版の別名リンクやコピーを識別する隔離機能は持たない。
`process_start` は同じ OS ユーザーの権限で任意コマンドを実行する。停止は Desktop Commander のセッションのルート PID を対象とし、子孫を含む一括停止は保証しない。
終了コードが取得できない完了は不明のまま監査し、停止を確認できない場合は成功を捏造しない。

Google OIDC、CIMD、refresh token、複数PC、Funnel と ChatGPT の公開実接続は F01〜F03 の後続作業である。
公開サービスの有効化やマージは行わない。
