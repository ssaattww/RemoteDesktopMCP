# 機能要件

## 目的

RemoteDesktopMCP は、許可された単一ユーザーがリモートから対象 PCのファイル操作およびプロセス操作を行うための MCP サーバーとする。
初期版では必要最小限の機能に限定する。

## 認証

- OAuth/OIDC によりリモート接続ユーザーを認証する。
- あらかじめ登録された1ユーザーだけアクセスを許可する。
- 登録ユーザー以外からのアクセスは拒否する。
- 許可ユーザーの設定変更は対象 PCのローカル操作からのみ可能とする。
- MCP ツール から許可ユーザーを変更する機能は提供しない。

## セッション管理

- 接続ごとにセッションを識別できること。
- セッションごとに一意な `session_id` を持つこと。
- 現在のセッション一覧を取得できること。
- 各セッションの最終活動時刻を記録すること。
- 起動したプロセスと、それを起動したセッションを関連付けること。

## ファイル操作

- ファイル名およびパスからファイルを検索できること。
- ファイル内容から文字列を検索できること。
- テキストファイルの内容を読み取れること。
- ファイルへ部分的な変更（パッチ）を適用できること。

初期版で公開するツール:

- `file_search`
- `content_search`
- `file_read`
- `file_patch`

## プロセス操作

- コマンドまたはプログラムを起動できること。
- 起動したプロセスの実行状態を取得できること。
- stdout および stderr を取得できること。
- 起動したプロセスを停止できること。
- プロセスの終了コードを取得できること。

初期版で公開するツール:

- `process_start`
- `process_status`
- `process_output`
- `process_kill`

## ログ

- MCP 経由で行われた操作を記録すること。
- 認証成功および認証拒否を記録すること。
- セッションの開始および活動を記録すること。
- プロセス起動時にコマンド、PID、セッションを記録すること。
- プロセス終了時に終了結果を記録すること。
- 操作の成功だけでなく拒否および失敗も記録すること。
- ログ機能およびログ設定変更機能は MCP ツール として公開しない。

## セッション用ツール

初期版で公開するツール:

- `session_list`

## 初期版の対象外

認証設定および許可ユーザー設定は MCP ツール として公開しない。

## 公開経路

- 外部公開には Tailscale Funnel を使用する。
- 固定グローバル IP を前提としない。
- ルーター／モデムのポートフォワーディングを必要としない。
- RemoteDesktopMCP は ループバック (`127.0.0.1`) のみにバインド する。
- 外部クライアントは Tailscale Funnel が提供する HTTPS URL から接続する。
- Funnel は認証境界として扱わず、RemoteDesktopMCP 自身が全 MCP 要求を認証・認可する。
- Funnel の設定変更機能は MCP ツール として公開しない。

詳細は `tailscale-funnel-architecture.md` を参照する。
